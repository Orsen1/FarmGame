# Покупка семян и исправления сервисов

Код подготовлен под присланные InventoryService, MoneyService, SellHandler и ItemDefinitions.

## Подключение

1. Обнови существующие ModuleScript InventoryService, MoneyService и SellService в ServerScriptService содержимым одноимённых файлов. Сохрани их имена.
2. Обнови существующий Script SellHandler содержимым SellHandler.server.lua. Вторую копию обработчика не создавай.
3. Создай ModuleScript BuyService в ServerScriptService и вставь BuyService.lua.
4. Создай RemoteEvent BuyItemEvent в ReplicatedStorage/RemoteEvents.
5. Создай Script BuyHandler в ServerScriptService и вставь BuyHandler.server.lua.
6. ItemDefinitions в ReplicatedStorage/Configs оставь со своими BuyPriceCents и SellPriceCents. Цены задаются в целых центах.

В проекте Rojo файлы обработчиков имеют суффикс .server.lua; файлы модулей — .lua. Помести их в директории, уже связанные с нужными объектами ServerScriptService. Архив не содержит и не заменяет default.project.json.

## Проверка без GUI

Запусти Play в Studio. Выполни в серверном контексте Command Bar:

```lua
local player = game:GetService("Players"):GetPlayers()[1]
local BuyService = require(game:GetService("ServerScriptService"):WaitForChild("BuyService"))
local success, reason = BuyService.BuyItem(player, "CarrotSeed", 3)
print(success, reason)
```

При цене 2 цента покупка трёх семян уменьшает баланс на 6 центов и добавляет три семени. При недостатке денег или заполненных шести слотах без подходящего стека баланс и инвентарь остаются прежними. Если стек семян уже существует, добавление в него возможно даже при занятых остальных слотах.

Будущая кнопка покупки в LocalScript:

```lua
game:GetService("ReplicatedStorage"):WaitForChild("RemoteEvents")
	:WaitForChild("BuyItemEvent"):FireServer("CarrotSeed", 1)
```

Обработчик пока не отправляет отдельный ответ для GUI: данные денег и инвентаря обновляются через существующие реплицируемые объекты. Проверку доступности магазина по расстоянию добавим, когда появится магазин и будет определено, где им разрешено пользоваться. Сейчас разрешена покупка предметов с BuyPriceCents из любой точки.

## Что исправлено

- Проверки предмета и положительного целого количества в InventoryService, BuyService и SellService; NaN и бесконечности отклоняются.
- Отрицательные, дробные и некорректные суммы не принимаются MoneyService. Ноль разрешён для бесплатных операций.
- Добавлен InventoryService.CanAddItem: проверка свободного слота либо существующего стека без изменения инвентаря.
- Проверки выполняются без ожидания появления Inventory или MoneyCents: покупки до готовности данных отклоняются.
- Покупка проверяет место до списания; если AddItem вернул false, списанная сумма возвращается.
- Продажа проверяет возможность начислить деньги до удаления предметов и использует SellPriceCents.
- Повторная MoneyService.Initialize не обнуляет уже созданный баланс.
- BuyHandler и SellHandler принимают запросы одного игрока не чаще раза в 0.15 секунды. Данные ограничения удаляются при выходе игрока.
- Верхняя техническая граница чисел — 9007199254740991: максимальное целое, точно представимое обычным числом Luau.

## Результаты функций

Успех: true. Отказ: false и строка с причиной, например InventoryFull, InvalidAmount или ItemCannotBeBought. Код, использующий только первое возвращаемое значение, продолжит работать.

Эти операции рассчитаны на присланную модель инвентаря: шесть слотов и один неограниченный в игровых условиях стек каждого предмета. Сохранение прогресса пока не добавлено. При дальнейшем добавлении ожиданий или запросов к DataStore внутрь операции потребуется пересмотреть её целостность.
